# Как заменить картинки услуг

1. Положите свои изображения в эту папку, например `hands.jpg`, `feet.jpg` и `eyes.jpg`.
2. Откройте `index.html` и найдите `class="treatment-grid"`.
3. В каждой из трёх карточек найдите тег `<img ... src="...">`. Замените только значение `src` на путь к своему файлу:
   - `assets/images/hands.jpg` — руки;
   - `assets/images/feet.jpg` — ноги;
   - `assets/images/eyes.jpg` — глаза / ресницы.
4. Не удаляйте `data-i18n-alt`: он отвечает за перевод альтернативного текста картинки для доступности.
5. Имена файлов чувствительны к регистру на некоторых хостингах: `Hands.jpg` и `hands.jpg` могут считаться разными файлами.

Рекомендуется использовать JPG или WebP, примерно 1200×900 px. Старайтесь, чтобы все три фотографии имели похожий стиль и качество.
